# WHITE ARCH — Ultra-Premium Digital Experience

> **"Bridge the Gap: Precision, Made Visible."**

An ultra-premium, immersive corporate website for **White Arch**, a high-end electromechanical, HVAC, MEP, and critical infrastructure engineering firm operating across Saudi Arabia and the GCC.

Inspired by Swiss editorial discipline, architectural luxury, and contemporary industrial design.

---

## Key Features

- **Hero Experience**: Features the "Bridge the Gap" sunrise atmosphere with editorial serif typography and celestial sunrise framing.
- **3D Coordinated Digital Twin**: Signature 6-slice isometric exploded building schematic (Rooftop Chillers, HVAC Distribution, Electrical MV Substation, Tier IV Data Centre, Fire Life Safety, Base Infrastructure) with real-time interactive telemetry and layer isolation.
- **Kingdom-Wide Presence**: Stylized geodetic vector map of Saudi Arabia with coordinates for Dammam (HQ), Riyadh, Western Region (Jeddah), and Mobile units.
- **Technical Proposal Drawer**: Interactive RFP configurator for engineering disciplines, facility footprint, and regional jurisdiction.
- **Acoustic Atmosphere**: Ambient Web Audio API synthesized 48Hz resonant engineering frequency with mute toggle.
- **Custom Precision Cursor**: Dual reticle desktop cursor with magnetic image `VIEW ↗` mode.

---

## Tech Stack

- **Framework**: React 18 + Vite 6
- **Styling**: Tailwind CSS with custom warm architectural dawn palette
- **Motion & Transitions**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Fraunces & Cormorant Garamond (Serif), Inter (Sans), IBM Plex Mono (Technical Mono)

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd StoreBox

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` to explore the experience.

### Production Build

```bash
npm run build
npm run preview
```
